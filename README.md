# ascended-plugins

Dalamud plugin repository for my `ascended-*` plugins.

## Install in Dalamud

Add this URL to Dalamud's Custom Plugin Repositories (`/xlsettings` → Experimental → Custom Plugin Repositories):

```
https://raw.githubusercontent.com/jkleinne/ascended-plugins/main/pluginmaster.json
```

All `ascended-*` plugins listed below become available in Dalamud's plugin installer.

## Available plugins

- **Ascended Rotation Solver Reborn** — Personal fork of RotationSolverReborn that adds PvPSmart, a scoring-based PvP target selector. Source: [ascended-rotationsolverreborn](https://github.com/jkleinne/ascended-rotationsolverreborn)
- **Ascended Dagobert** — Personal fork of Dagobert, a Dalamud plugin that adjusts your market board prices to 1 gil below the cheapest listing. Source: [ascended-dagobert](https://github.com/jkleinne/ascended-dagobert)
- **Ascended ezWondrousTails** — Personal fork of EzWondrousTails, a Dalamud plugin that shows Wondrous Tails row probabilities, exact shuffle averages, and shuffle advice. Source: [ascended-EzWondrousTails](https://github.com/jkleinne/ascended-EzWondrousTails)
- **Ascended Ledger** — Market and retainer-sales intelligence: reads your retainer listings and completed sales from the game client and pairs them with board-wide market context (listings, sales history, velocity) from the Universalis API. Source: [ascended-ledger](https://github.com/jkleinne/ascended-ledger)
